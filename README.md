# CyberInvestigator

A standalone cybersecurity learning prototype with role-based stories, varied case lengths, shuffled dialogue choices, weighted ability radar, replay, and device-local progress.

## Run locally

```sh
python3 -m http.server 8000
```

Open <http://localhost:8000>. No install, API key, or build step is required.

The current live demo is <https://signal-room-cyber-sim.kind-berry-9383.chatgpt.site>. Feedback is scripted and progress is saved in each visitor's browser localStorage.

This is an independent, history-free prototype branch. It does not include or replace the repository's Next.js application on other branches.
